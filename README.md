# JPMorgan Chase — Software Engineering Virtual Experience

A collection of code patches and exercises associated with the JPMorgan Chase & Co. virtual software-engineering learning programme.

## Repository contents

- `JPMC-tech-task-1-py3/`, `JPMC-tech-task-2-PY3/`, `JPMC-tech-task-3-PY3/` — task workspaces.
- `Patch files/` — related submitted or practice changes.
- Completion material and `LICENSE` — consult the files for context and attribution.

## What this demonstrates

Practice reading an existing codebase, working from engineering tasks, producing patches and understanding the structure of a finance-related development workflow.

## Running the exercises

Open the appropriate task folder and read its project-specific instructions. Python version and dependencies vary by task; run only in an isolated development environment. No live financial systems or customer data are included by design.
